見た目プレビュー
このアプリの使い方

このアプリで、ホームページの文章や写真を、Gitなどの専門知識なしに更新できます。基本の流れは「ページを選ぶ → 直す → 右で確認 → 保存 → 公開」です。

1. 編集するページを選ぶ

  1. 左の一覧から、直したいページ（またはブログ）を選びます。

2. 文章・写真を直す

  1. まん中の入力欄で、文章を書き換えます。
  2. 料金表・質問と回答・ブログ記事などは、「◯◯を追加」で行を増やせます。各行の右のアイコンで、上下の並べ替えや削除ができます。
  3. ブログ記事は「タイトル」「日付」「写真」「本文」を入力するだけで作成できます（記事IDや一覧用の紹介文は自動生成されます）。ページ全体の見出しなどは下部の折りたたみから変更できます。
  4. 写真は、いまのところ「写真の場所」を入力する方式です（本番公開後の画面では、写真を直接アップロードできます）。

3. 右のプレビューで確かめる

  1. 右側に、実際の見た目が表示されます。入力するとすぐ反映されます。
  2. 上の切り替えで、「現状」（今のサイト）・「変更後」（直したあと）・「並べて比較」を選べます。

4. 下書きを保存する

  1. 「下書きを保存」を押すと、編集内容が保存されます。まだ本番サイトは変わりません。
  2. 「戻る」ボタン（上部・下部の両方にあります）は、直前のひとつの操作だけを取り消します。何度か押すと、そのぶんだけさかのぼれます。押せるのは、このページを開いている間だけです。
  3. 「最初の状態にリセット」は、保存した下書きも含めて、このページを開く前の状態まで一気に戻します。押すと確認のポップアップが出ます。
  4. 保存していない変更があるまま他のページに移動しようとすると、「保存して移動／保存せず移動／キャンセル」を選ぶ画面が出ます。

5. 確認して公開する

  1. 「実ページで開く」で、サイト全体の中での見え方を確認します。
  2. 問題なければ公開します。公開すると、本番サイトに反映されます。

この先行運用版は「下書き」までの確認用です。本番への公開の反映は、管理者が設定した公開のしくみを通じて行われます。チャットで直せる機能は、今後追加を検討しています。
