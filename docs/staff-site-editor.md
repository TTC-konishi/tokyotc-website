# TTC ホームページ編集アプリ（MVP）

## 目的

専務・スタッフがGitの操作を覚えずに、ホームページの文章と写真を安全に更新できるようにする。

## 入口と機能境界

- `/staff/`: ページ検索と会話型の変更案プレビュー。変更案は利用端末の `localStorage` にだけ保存され、Git保存・PR・本番公開は行わない。
- `/admin/`: 招待された担当者が使う認証付きのDecap CMS。実際のGit保存、下書き、承認、公開はこちらで行う。

会話型画面で作った変更案は、通常のお客様向けURLには反映されない。`?assistant=` または `?proposal=` が付いた確認用URLだけに表示される。

## 実際に公開する操作

1. `https://tokyotc.com/admin/` を開く。
2. 招待されたメールアドレスでログインする。
3. 「婚活サイト」から「選ばれる理由」を開く。
4. 文章または写真を変更し、下書きとして保存する。
5. 確認用ページで表示を確認する。
6. 内容を承認して公開する。

## 現在の対象範囲

- 婚活サイト「選ばれる理由」
- ページ見出し
- はじめの説明文
- 3つの理由の見出しと本文
- 各理由の写真と写真説明

## 公開前に必要な管理者設定

このコードを本番へ反映した後、Netlify管理画面で一度だけ次を設定する。

1. Ownerが認証方式を選択する。
2. 先行運用としてGit Gatewayを選ぶ場合のみ、Identityを有効にし、直ちに新規登録を招待制にする。
3. Git Gatewayを有効にする（deprecatedのため将来置換が必要）。
4. Ownerが指定した編集担当者だけをメールアドレスで招待する。
5. Deploy Previewが有効であることを確認する。

設定完了後は、通常の更新作業でNetlifyやGitHubを開く必要はない。

## 仕組み

- 編集画面: Decap CMS
- ログインと編集者管理: Netlify Identity
- 下書き・履歴・承認: Git GatewayとEditorial Workflow
- 公開前確認: Netlify Deploy Preview
- 公開: 承認された変更のみ`main`へ反映し、Netlifyが自動配信
